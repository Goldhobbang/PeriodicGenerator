# 원소 문장 실험실

배포 주소: [GitHub Pages에서 열기](https://goldhobbang.github.io/PeriodicGenerator/)

`index.html`을 브라우저에서 열면 바로 실행되는 정적 웹입니다. 설치, 빌드, 서버, 외부 라이브러리 및 네트워크 연결이 필요 없습니다.

- 입력 즉시 영어 단어를 118개 원소 기호로 분리합니다.
- 영어 기호(대소문자 준수) / 한국어 이름을 선택할 수 있습니다.
- 공백, 줄바꿈, 문장부호 및 비영문 문자를 보존합니다.
- 원소에 대응하지 않는 영문 글자는 원문 그대로 남기고 주황색 카드로 표시합니다.
- 복사 버튼은 현재 선택한 언어의 문자열을 복사합니다. 한국어 이름 사이에는 `·`를 넣어 원소 경계를 표시합니다.
- 입력은 브라우저에서만 처리하며 최대 3,000자입니다.

## 분리 알고리즘

영문 단어마다 뒤에서 앞으로 동적 계획법을 적용합니다. 각 위치에서 1글자 원소, 2글자 원소, 원문 1글자 보존을 비교합니다. 비교 우선순위는 (1) 미변환 글자 수 최소화, (2) 원소 수 최소화, (3) 앞쪽 2글자 원소 우선입니다. 따라서 단순히 2글자씩 탐욕적으로 선택했을 때 놓치는 완전 변환도 찾습니다. 예를 들어 `bag`에서 `Ba`를 먼저 선택하면 `g`가 남지만, 이 알고리즘은 `B + Ag`를 찾습니다. 비용과 다음 선택만 저장하므로 시간·공간 복잡도는 O(n)입니다.

`node test.js`로 알고리즘 검증을 실행할 수 있습니다.
